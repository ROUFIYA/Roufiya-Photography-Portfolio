THROUGH MY LENS — Photography by Roufiya
==========================================

Your custom, responsive photography portfolio website.

PREVIEW LOCALLY
1. Extract the ZIP file.
2. Open the "through_my_lens" folder.
3. Double-click index.html to preview it in your browser.
   Internet is required for the demo photographs and Google Fonts.

PERSONALISE BEFORE PUBLISHING
- Replace the demo photographs in index.html with your own image URLs or local image paths.
- Update the About section to tell your own story.
- Replace hello@example.com with your real email address.
- Replace the sample journal entries with your own stories or remove that section.
- Update the copyright year if needed.

PUBLISH FREE
Option A — GitHub Pages:
1. Create/sign in to a GitHub account.
2. Create a public repository (for example, through-my-lens).
3. Upload index.html, style.css, script.js and README.txt (plus any local images).
4. Open Settings → Pages.
5. Under Build and deployment, choose "Deploy from a branch", select main and / (root), then Save.
6. GitHub will provide a free public website address.

Option B — Netlify:
1. Create/sign in to Netlify.
2. Choose Add new site → Deploy manually.
3. Drag the extracted website folder into the deployment area.
4. Netlify will provide a free public website address.
